# Clone Avito API 


### Пользователи
- Регистрация и вход в систему
- Профиль
- Роли: пользователь и администратор

### Категории
- Список категорий
- Только администратор может создавать, изменять и удалять категории

### Товары
**Продавец может:**
- Создавать, редактировать и удалять свои товары
- Указывать название, описание, цену, категорию, город, фотографии и статус
- Статусы товара: активен, зарезервирован, продан или архивирован

**Покупатель может:**
- Просматривать ленту товаров с разбивкой на страницы
- Смотреть карточки товаров
- Искать товары по названию и фильтровать по категориям
- Добавлять товары в избранное, удалять их оттуда и просматривать список избранных

### Заказы
Процесс покупки включает:
- Проверку баланса
- Списание средств
- Создание заказа

**Статусы заказа:** 
- оплачен
- выполнен
- отменён

**Покупатель может:**
- Просматривать свои заказы
- Отменять их (что приводит к возврату денег)

### Кошелёк
- Баланс
- Пополнение
- История транзакций
